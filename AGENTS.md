# cyrene-terminal

Native Go application using MyGo 0.7.4. Native UI shell; optional embedded WebView panes for user-requested website browsing. No web-based application shell, Vite or Vite+.

Follow `.agents/skills/mygo-maintenance/SKILL.md`. Read the pinned module source before using APIs. Never store `ui.Element` or capture `*ui.Context` in workers; keep state on the UI thread and publish work with `Window.Update`.

Commands: `go tool mygo dev`, `go tool mygo build -skip-installer`, `go tool mygo vet .`, `CGO_ENABLED=0 go test ./...`.

Closing the window hides the whole application to the tray and keeps terminals running. There is no separate detached/background-session feature. Closing a terminal tab requires confirmation and then ends its process. The tray context menu is the explicit application exit route. Keep starting processes and other slow I/O out of view construction.

The UI has no left or right sidebar. The 50-DIP title bar contains 34-DIP workspace groups with about 9-DIP top breathing room balanced against the content gap, an add button inside the selected workspace (never inside a standalone tab), a global new-workspace + immediately left of appearance settings, with no brand label or dedicated command-palette icon; Ctrl+Shift+P remains the command entry. Only the selected workspace expands inline to expose its child pane tabs when it has multiple panes; selecting another workspace collapses the previous one. Child tabs focus their existing pane and can be dragged independently; dragging a workspace label reorders the whole screen with its layout and alias intact. Keep the strip constrained before caption/tool controls, with horizontal wheel/trackpad scrolling and automatic reveal of the selected child. Use 13-DIP tab text, roomier child spacing, and translucent selected fills with fine edge highlights. Default workspace names are Workspace, Workspace2, etc.; persist the sequence and per-screen index independently of user aliases and standalone session labels. The global + creates an explicit workspace; Ctrl+Shift+T still creates an independent tab. Use rounded translucent workspace groups and subtle child highlights, never opaque Theme.Background patches. Workspace and child-tab close buttons are always visible siblings of their selection buttons, reserving width and exposing independent accessible actions. Child tabs reorder independently of the spatial layout, and persist their order. Dropping an external pane or whole workspace inside a group joins it, preserving the original subtree and session/process ownership; only the outer 12-DIP group edges reorder whole groups.

Use ordinary frosted glass: native VibrancyAcrylic supplies the desktop blur; panes and tabs have faint translucent fills, raised bevel gradients and restrained inner/outer shadows, with stronger lower return highlights. Selected groups and focused panes have clearly stronger rims/tints. No liquid refraction. Pane titles use 13-DIP type and available embedded Agent icons; omit unavailable process icons. Only pane action buttons reveal on focus or hover, with animated width and opacity; icons are independent of focus. Animate child selection and matched pane geometry during docking, addition and removal. Keep transparent half-DIP layout borders to avoid geometry shifts. Popups use uniform glass.Blur with replacement backdrop compositing plus a light neutral tint and a raised rim/shadow, never glass.Glass. The vendored CPU/D3D11 replacement patch preserves filtered alpha instead of blending sharp content back underneath. During overlays, asynchronously capture loaded browser panes and temporarily show their bitmap frames so native web content participates in the same blur; keep the page loaded, reject stale captures, and restore the live view after exit motion. Never re-sample the window backdrop per pane, which duplicates alpha. Keep a compact gap of about 8 DIPs from tabs to content. Workspace children expand/collapse with a continuous, non-bouncing spring and opacity, retaining motion when interrupted; compute target width from native text metrics, never from a clipped/animated width. Do not paint extra splitter lines; retain native resize hit areas and keyboard resizing. Any terminal or browser pane can dock on another pane's edge, with previews, or detach by dragging its header/child tab to the top strip. Keep layout ownership separate from process/browser ownership: docking, detaching and switching must not restart terminals or reload browsers. Preserve directory, group, aliases and focus. Omit group labels entirely for ungrouped sessions. Ctrl+Shift+P provides searchable commands for splitting with existing/new terminal or browser panes, focusing, detaching, balancing, renaming and group management. Naming commands affect only the focused workspace/session. The titlebar view owns the OS window title.

Folder bindings remain available through command-palette group launch commands, without a sidebar. The in-workspace add button is circular (26 DIPs, radius 13) and opens a compact launcher without group selector or directory row. Capture the opener pane: terminal and website choices append to that workspace and inherit that pane directory/group even if focus changes; prefer the roomier split direction. New split panes inherit the target's directory and group. Independent terminal launch via palette/shortcut uses the selected group or the user home directory. Prefer session aliases, then the current working directory basename; OSC titles are only a fallback. Browser labels use an alias, page title, then hostname. Launchers are popovers below their actual local/global opener. Modals/popovers use continuous damped springs with restrained overshoot and interruption continuity. Buttons animate hover colors in both directions. Preserve multicolor Agent SVGs with ui.Image.

The application shell and terminals remain native Go UI. Website panes are an explicit exception: embed MyGo WebView with Untrusted:true, no Go bridges, and HTTP(S)-only navigation. Creating a website pane opens a native empty state with its address focused, without a modal or any initial network request. Provide address, back, forward, reload and close controls. Inset the browser viewport by 4 DIPs with a 10-DIP page radius, within the 12-DIP outer pane. The vendored MyGo Windows backend clips the actual DirectComposition WebView visual using a rounded rectangle; radii also flow to hit testing and zoom. Never cover corner cutouts with opaque black backing. See docs/mygo-webview-patch.md and scripts/refresh-vendor.ps1. Preserve transparency around that local viewport. Persist blank website panes with an explicit browser marker. Ctrl+L focuses the current browser's address. Create WebViews off the UI thread, publish via Window.Update and reject/destroy orphaned creations after closure. Hide inactive pages without destroying them; destroy only on close or application exit. Git diff and native file preview remain deferred.

Project layout: `cmd/cyrene-terminal` is the entry point configured by `mygo.json`; implementation and tests live in `internal/app`. Embedded branding lives in `assets`; distribution files live in `resources`. Run all commands from the repository root. Windows wrappers are `scripts/dev.ps1` and `scripts/build.ps1`. Build acceptance binaries with `go build -tags e2e -o .mygo/cyrene-isolated-smoke.exe ./cmd/cyrene-terminal`.

Persist the workspace to a separate workspace.json before explicit application exit, then restore directories, aliases, session ownership, screen order/layout/focus and browser URLs at startup. Restart shells in their stored directories; resume agents only by their exact saved conversation ID. Codex and Claude use per-launch SessionStart hooks and per-pane ID record; preserve normal hook trust review, do not bypass it in production or change global agent configuration/identity. Missing Codex/Claude IDs open the agent native history picker in the original pane, without requiring pasted IDs or guessing the latest conversation; custom agents without a picker retain manual binding. Claude hook injection must preserve explicit settings and existing hooks. Poll once more at process exit to capture late ID records. Save disk data off the UI thread and await successful save before terminating processes. Tabs must stay within the header, reserving tool/caption width, scroll horizontally on wheel/trackpad and reveal a newly selected tab. Branding is the editable wink/terminal >_ SVG; regenerate both PNG assets through scripts/render-icon.

Browser toolbar is 44 DIPs high, with additional top padding, 28-DIP address input and centered 26-DIP SVG controls. Refresh vendor through scripts/refresh-vendor.ps1 to retain both native corner and frosted compositing patches; preserve LF in embedded shader sources.
